# Sanaya & Rajesh — the heirloom invitation

One final ivory, burgundy and antique-gold design, with the approved sculpted Ganesha, elephants and smaller 3D names. Earlier theme controls and query parameters have been retired.

## Preview
Run `python3 -m http.server 4173` in this directory, then open http://localhost:4173.

## Experience
- Full-screen embroidered velvet curtains open when the gold seal is tapped. Skip, Escape, replay and reduced-motion support are included.
- The approved artwork is preserved as the invitation centerpiece and downloadable original PNG. Optimized JPEGs serve the web page.
- Gold-edged dimensional event panels, raised typography, animated light sweep and five slideshow scenes; optional photos can be added in `config.js`.
- Swipe/keyboard slideshow controls, play/pause, full screen where supported, date-only calendar reminders, venue search and native sharing/clipboard fallback.
- Gentle motion can be disabled in the footer; system reduced-motion settings are respected.
