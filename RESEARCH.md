# Wedding interaction research — 26 November 2026

Research subagent reviewed repository documentation and license files, not a full code audit or mobile performance test.

- [thesurajdev/wedding-invite](https://github.com/thesurajdev/wedding-invite): strongest cultural/technical fit; plain HTML/CSS/JS, staged envelope reveal, swipe event carousel. [MIT code](https://github.com/thesurajdev/wedding-invite/blob/main/LICENSE); original photos/music/video/personal details excluded.
- [thekimberleyann/waddle](https://github.com/thekimberleyann/waddle): configurable invitation with staged envelope animation and countdown. [MIT](https://github.com/thekimberleyann/waddle/blob/main/LICENSE); Next.js/React/Motion stack.
- [nguyenhuugiatri/iphone-wedding-invitation](https://github.com/nguyenhuugiatri/iphone-wedding-invitation): lock-screen and mini-app invitation metaphor. [MIT code](https://github.com/nguyenhuugiatri/iphone-wedding-invitation/blob/main/LICENSE); media/components can carry separate terms.
- [Rainier-PS/Invitation-Template](https://github.com/Rainier-PS/Invitation-Template): configurable content, theme settings, motion toggle, carousel. Repository identifies MIT licensing.
- [thrinathpolanki/wedding-invitation-site](https://github.com/thrinathpolanki/wedding-invitation-site): scratch reveal, petals, envelope, keyboard/swipe gallery. Describes personal/family use; not a verified permissive license. Inspiration only.

Implementation uses original code and artwork. Shared interaction ideas: short replayable opening, restrained petals, swipe slides, persistent theme picker, pause and reduced-motion support. No external code or media was copied.
